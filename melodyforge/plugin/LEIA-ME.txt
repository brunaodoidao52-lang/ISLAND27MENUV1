MelodyForge ISLAND27 — versão 2.1 para Windows (64 bits)
=========================================================

O QUE TEM AQUI
  MelodyForge ISLAND27.exe    app independente (não precisa de DAW nenhuma)
  MelodyForge ISLAND27.vst3   plugin VST3 para o FL Studio (e outras DAWs)
                              -> os timbres reais ficam dentro dela, em
                                 Contents\Resources\MelodyForge-Timbres.sf2

APP INDEPENDENTE (.exe)
  Deixe o .exe na MESMA pasta da pasta "MelodyForge ISLAND27.vst3" (como vem
  no zip) ou instale o VST3 (abaixo): é de lá que ele carrega os timbres.
  Dê dois cliques. Se o Windows avisar "O Windows protegeu o computador",
  clique em "Mais informações" > "Executar assim mesmo" (o arquivo não tem
  assinatura digital). Em Options > Audio/MIDI Settings escolha a saída de áudio.

INSTALAR O VST3 NO FL STUDIO
  1. Copie a PASTA "MelodyForge ISLAND27.vst3" inteira (com a subpasta
     Contents\Resources) para  C:\Program Files\Common Files\VST3\
  2. FL Studio > Options > Manage plugins > Find more plugins.
  3. Ele aparece como gerador: "MelodyForge ISLAND27" (Island27).
     Adicione no Channel Rack.

COMO USAR (modo Iniciante)
  1. Escolha um estilo (Trap, Lo-fi, Funk BR...) e um clima (Alegre, Triste...).
     O estilo também escolhe timbres que combinam (ex.: Trap = 808 no baixo).
  2. Clique em "Gerar ideias" e em "Tocar".
  3. "Curti" no que gostar, "Pular" no resto. No modo Avançado, "Evoluir"
     cruza as melhores ideias e cria a próxima geração.
  4. Arraste um dos blocos "Tudo / Melodia / Baixo / Acordes" para o piano
     roll ou a playlist do FL Studio — ou use "Exportar MIDI...".

  Os cartões MELODIA, BAIXO e ACORDES explicam o que é cada parte. Em cada um:
  liga/desliga, timbre, volume, "Ouvir só" (toca só aquela parte) e
  "Nova variação" (refaz só aquela parte).

TOCAR SEPARADO OU JUNTO COM O FL
  Por padrão o MelodyForge NÃO toca quando você aperta espaço no FL: ele só
  toca pelo botão "Tocar" dele. Para tocar junto com o projeto (no andamento
  e na posição do FL), ligue "Tocar junto com o FL Studio".

TIMBRES REAIS
  58 instrumentos gravados (piano, Rhodes, violões, baixos, cordas, coral,
  metais, sax, flautas, sintetizadores, pads...) + 3 sons sintetizados
  (808, pluck, seno). No modo Avançado, "SoundFont..." carrega qualquer
  outro banco .sf2 seu; "Timbres padrão" volta para o banco original.

TELA CHEIA
  Botão "Tela cheia" no canto superior direito; clique de novo para voltar
  ao tamanho normal. Você também pode arrastar o canto da janela: o texto
  cresce junto.

MIDI PARA OUTROS INSTRUMENTOS
  No wrapper do plugin (engrenagem) defina uma porta em "MIDI > Output port"
  e use a mesma porta como "Input port" no instrumento.
  Melodia = canal 1, baixo = canal 2, acordes = canal 3.

Tudo é salvo junto com o projeto do FL (ideias, semente, estilo, timbres e
edições).
