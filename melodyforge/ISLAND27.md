# MelodyForge — edição ISLAND27

Versão do [MelodyForge](README.md) (MIT, © 2025 James The Giblet) com a identidade
visual da ISLAND27. **Por enquanto só mudaram as cores e o avatar.** O nome, os
textos, as fontes e todo o funcionamento continuam iguais ao original.

## O que mudou

| Antes | Depois (paleta do site island27) |
|---|---|
| Fundo roxo-azulado `#1a1a2e → #16213e` | `#08090C` / `#0C0E13`, com brilho `#2AA9E0` no topo |
| Cartão translúcido branco | `#14161C` (82%), borda branca a 8% |
| Turquesa `#4ecdc4` / `#44a08d` | Ciano `#7FE3FF` / azul `#2AA9E0` |
| Vermelho `#ff6b6b` (Skip, Pause, Export, Delete) | Marinho `#12213F` com borda clara |
| Roxo, laranja, azul (Evolve, MIDI, Share) | Combinações de `#12213F`, `#2AA9E0`, `#4DC0F0`, `#7FE3FF` |
| Visualizadores `#0f3460` | `#0C0E13` |
| Notificações verde/amarelo/vermelho | `#2AA9E0` / `#1D8FC2` / `#12213F` |
| Texto branco | `#F2F4F8`; texto escuro `#04141C` nos botões claros (como o `.btn-primary` do site) |
| Ícone 🎵 no cabeçalho e na aba | Avatar ISLAND27 (montanha com coqueiro), embutido no próprio HTML |

O app continua precisando de internet para carregar o Tone.js (cdnjs), como no original.
