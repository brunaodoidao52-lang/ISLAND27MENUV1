# Engenharia reversa — "Lemonade" (Internet Money) → nova letra "Preto e Branco"

## 1. Raio-X da letra original

### Estrutura
| Bloco | Linhas | Função |
|---|---|---|
| Intro | 3 tags curtas entre parênteses | ad-libs, assinatura do produtor ("Internet Money") |
| Refrão (hook A) | 4 | escolha + ostentação + "vou estourar" + "roubam meu flow" |
| Pós-refrão (hook B) | 5 | crescimento → todo mundo quer parte → imagens em pares ("two twin…") |
| Verso 1 | 8 | lista de marcas + "comecei de baixo" + inimigos/origem |
| Verso 2 | 4 | mulheres/DM + "não me quis antes" + quem torce contra |
| Hook A + B | ×2 | repetição para fixar |

Forma final: **Intro → Hook → Verso → Hook ×2**. Pouco verso, muito refrão — feito para grudar.

### Fórmulas que fazem funcionar
1. **Pergunta de escolha binária**: "I got X, I got Y, what you want?" — abre o refrão e o verso com a mesma moldura, trocando só as cores (black/white → red/blue).
2. **Upgrade em sequência**: sair de um carro de luxo e entrar em outro ainda maior (Ghost → Phantom).
3. **Pares numéricos repetidos**: "two twin… / two twin… / two thick…" — anáfora que dá ritmo.
4. **Lista de marcas** em uma linha só (Chanel, Balenciaga, Louis, Fendi, Prada) + um lugar de luxo (Milan).
5. **Arco "antes vs. agora"**: "started from the bottom", "you ain't want me last year".
6. **Monorrima por bloco**: cada bloco segura um único som final.
   - Refrão + Verso 1: som "-ʌn / -æn" (want / Phantom / dumb / ransom / Vuitton / Milan / one / ton / from)
   - Pós-refrão: "-ancer / -anner" (dancer / banner)
   - Verso 2: "-ace" (place / face / taste / laced)
7. **Métrica**: ~10–13 sílabas por linha, com pausa forte no meio ("I got black, | I got white").

### Mapa de rimas da versão nova
- Refrão + Verso 1: **-ão** (opção / irmão / não / milhão / Milão / salão / cordão / região / chão) — mesmo papel do "-um/-om" do original.
- Pós-refrão: **-ar** (dançar / olhar / colar) no lugar de "dancer / banner".
- Verso 2: **-ada** (madrugada / calçada / provada / palhaçada) no lugar de "-ace".
- Troca deliberada: as armas do original ("two twin Glocks") viraram "dois graves no talo" — mantém o par numérico e o "faço você dançar" sem a referência violenta.
