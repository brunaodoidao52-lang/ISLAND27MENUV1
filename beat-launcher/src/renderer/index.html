Onde conseguir clipes animados (sem problema de direitos)
  • Pexels e Pixabay (vídeos): grátis, inclusive para uso comercial.
  • Mixkit e Coverr: clipes curtos grátis, bons para fundo.
  • IA (foto → vídeo): Runway, Kling, Luma ou Pika animam a sua capa com movimento “de verdade”.
  • CapCut: efeitos de “foto animada” e 3D zoom.
  • Evite trechos de filme, anime e clipe de outros artistas: o YouTube e o Instagram derrubam ou bloqueiam.

YouTube

Não conectado.

Como conseguir o Client ID (uma vez só, ~10 min)
  1. Entre em console.cloud.google.com e crie um projeto (ex.: “ISLAND27 Launcher”).
  2. Em APIs e serviços → Biblioteca, ative a YouTube Data API v3.
  3. Em Tela de consentimento OAuth: tipo Externo, preencha nome e e-mail e adicione o seu e-mail como usuário de teste.
  4. Em Credenciais → Criar credenciais → ID do cliente OAuth, escolha App para computador. Copie o Client ID e o Secret para cá.
  5. Clique em Conectar YouTube e autorize no navegador com a conta do canal.

⚠ Enquanto o projeto estiver em “Teste”, o Google pede para reconectar a cada 7 dias. Para não expirar, clique em Publicar app na tela de consentimento (aparece um aviso de “app não verificado”, é só continuar).

⚠ Projetos novos enviam vídeos como privados até passar pela auditoria gratuita do YouTube (formulário “YouTube API Services - Audit and Quota Extension”). Enquanto isso, o vídeo sobe e você só muda para público no YouTube Studio.

Instagram

Não conectado.

Como conseguir o token (uma vez só)
  1. Passe o Instagram para conta Profissional (Criador ou Empresa) no app do Instagram.
  2. Em developers.facebook.com/apps, crie um app do tipo Empresa e adicione o produto Instagram → API com login do Instagram.
  3. Em Gerar tokens de acesso, adicione a sua conta, autorize e copie o token e o ID que aparecem.
  4. Cole aqui e clique em Salvar e testar. O app renova o token sozinho antes de vencer (60 dias).

⚠ O Instagram não aceita agendamento pela API: o Reels sai quando o app está aberto (ou na bandeja) na hora marcada. Se o PC estiver desligado, ele publica assim que você abrir.

IA MODO TESTE

Conecte a sua API (DeepSeek ou outra compatível com OpenAI) para a IA sugerir títulos, descrições, legendas e ideias de conteúdo. Fica desligada até você ativar; as sugestões só são usadas quando você aprova (a não ser que ligue “aplicar sozinho”).

Como pegar a chave da DeepSeek
  1. Entre em platform.deepseek.com e faça login.
  2. Em API Keys, crie uma chave e copie (ela só aparece uma vez).
  3. Coloque saldo na conta (a API cobra por uso; cada sugestão custa centavos).
  4. Cole aqui, confira o nome do modelo no painel e clique em Testar conexão.

A chave fica guardada criptografada neste computador e só é enviada para o endereço da API que você colocou.
